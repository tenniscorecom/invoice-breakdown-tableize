# 仕様書

このツールの処理仕様（保守する人向け）。コーディング規約は comken リポジトリの
`CONVENTIONS.md` に従う。

---

## 1. 目的・概要

外注先が作成する請求書内訳の Excel は、複数シート（実運用では数十枚）にわたって
「テーブル化されていない、ただの表」として届く。この状態だと、後続の自動処理
（種別ごとの分類・集計など）が列位置やシート構成のブレに弱くなる。

このツールは各シートの表を Excel の正式なテーブル機能（ListObject）へ変換するだけを行う、
最初の一歩のプロトタイプ。種別分類・按分などの業務ロジックはこのツールのスコープ外で、
入力側を構造化しておくことで、その種の後続処理を安定させるのが狙い。

---

## 2. 処理フロー

```
入力: config.ini [FILES] INPUT_FILE（複数シートの Excel。テーブル化されていない）
  ↓
コピー: 元ファイルは変更せず、OUTPUT_FOLDER 配下へ OUTPUT_PREFIX 付きでコピー
  ↓
変換: シートごとに使用範囲を取得し、comken の Excel.convert_range_to_table() でテーブル化
      （1 シートの変換失敗はスキップして次のシートへ進み、処理全体は止めない）
  ↓
出力: OUTPUT_FOLDER 配下の「OUTPUT_PREFIX + 元ファイル名」
```

---

## 3. 入出力

| 種別 | 内容 | 場所 |
|---|---|---|
| 入力 | 複数シートの Excel（各シートに非テーブルの表が1つ） | config.ini `[FILES] INPUT_FILE` |
| 出力 | 各シートをテーブル化した Excel（元ファイルとは別ファイル） | config.ini `[FILES] OUTPUT_FOLDER` |

---

## 4. 設定（config.ini）

| セクション | キー | 意味 |
|---|---|---|
| `[FILES]` | `INPUT_FILE` | 入力 Excel のパス |
| `[FILES]` | `OUTPUT_FOLDER` | 出力先フォルダ |
| `[EXCEL]` | `HEADER_ROW` | 見出し行の番号（1始まり）。全シート共通。未設定なら A2 ルールで自動推定 |
| `[EXCEL]` | `OUTPUT_PREFIX` | 出力ファイル名の先頭に付ける文字列 |


---

## 5. 構成

```
main.py            エントリポイント（ログ初期化・エラー受け）
config.ini         設定（.gitignore。初回実行時に example から作られる）
実行.bat            起動用（ターミナルから叩く。`pause` 無し＝無人実行向け）
認証情報の登録.bat   認証情報（ID・パスワード・client_secret）を DPAPI へ登録する画面
src/
  run.py             処理の本体
docs/
  使い方.md         操作手順（非エンジニア向け）
  仕様書.md         この文書
  ERRORS.md         エラー対応
```

comken は共有サーバーを直接参照する（`実行.bat` が起動時に `PYTHONPATH` を設定）。
恒久登録（社内 PC で `setup_comken.bat` を1度実行）も選べる。

---

## 6. 実行方法

- 通常: ターミナルで `実行.bat` を叩く（または `python main.py`）
- RPA 基盤から: `実行.bat` を絶対パスで起動する（終了コードで成否を判断する）か、`python <絶対パス>\main.py` を直接呼ぶ
- 動作確認: `main.py` を `with dry_run():` で囲むと、その範囲の保存・送信をスキップできる
